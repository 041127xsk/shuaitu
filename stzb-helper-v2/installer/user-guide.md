# stzbHelper 小白使用说明

这是给第一次使用的朋友看的版本。你只要按顺序做，不需要懂代码。

## 1. 安装软件

1. 双击 `stzbHelper-Setup.exe`。
2. 一路点击「下一步」或「安装」。
3. 如果弹出 Npcap 安装窗口，请继续安装。
4. 如果 Windows 弹出管理员权限提示，请点「是」。
5. 安装完成后，桌面会出现 `stzbHelper` 图标。

说明：
- Npcap 是抓包驱动，用来读取游戏战报数据。
- WebView2 是 Windows 桌面程序运行环境，安装包会自动处理。
- ADB 已经内置，不需要你自己找 `adb.exe`。
- 如果你电脑本来就有 MuMu 或 Android SDK 自带的 ADB，也可以在软件里点击「检索本机ADB」选择本机路径。

## 2. 准备模拟器和游戏

1. 打开 MuMu 模拟器。
2. 打开《率土之滨》并登录账号。
3. 进入游戏主界面。
4. 再打开桌面上的 `stzbHelper`。

如果软件提示需要选择数据库，默认数据库已经随安装包带好了，一般直接进入即可。

## 3. 检查抓包环境

1. 软件打开后，如果出现「需要安装 Npcap」页面，说明抓包驱动还没装好。
2. 按页面提示安装 Npcap。
3. 装完后关闭软件，重新打开。

正常情况下，装好 Npcap 后就能进入主界面。

## 4. 同步同盟成员

1. 在软件里进入「同盟成员」页面。
2. 点击「同步成员」，软件会提示你去游戏里打开同盟成员列表。
3. 回到游戏，打开「同盟」里的成员列表。
4. 等几秒后回到软件，点击「刷新」。

如果成员还是没更新：
- 确认游戏里真的打开了同盟成员列表。
- 确认 Npcap 已安装。
- 确认软件连接的是你想用的数据库。
- 关闭软件后重新打开，再试一次。

## 5. 采集队伍战报

1. 在首页找到「详细战报采集」或「战报采集」开关。
2. 点击开启。
3. 回到游戏，打开同盟战报页面。
4. 软件会自动抓取打开过的战报数据。
5. 采集结束后可以关闭采集开关。

提示：
- 如果日志显示很多重复战报，可能是当前数据库里已经有这些战报。
- 首页会显示当前写入的数据库、新增数量和重复数量。

## 6. 自动翻页采集历史战报

1. 先打开 MuMu 模拟器和游戏。
2. 在软件首页找到模拟器/ADB 选择区域。
3. 点击扫描或检查连接。
4. 如果有多个 MuMu 实例，选择正在运行游戏的那个。
5. 打开游戏里的同盟战报页面。
6. 点击开始自动翻页。

如果连接失败：
- 确认 MuMu 已经启动。
- 确认游戏在当前模拟器里。
- 点击重新扫描模拟器。
- 如果内置 ADB 不能连接，可以进入自动翻页/模拟器实例设置，点击「检索本机ADB」，选择 MuMu 或 Android SDK 自带的 ADB。
- 如果有多个端口，逐个选择后点检查连接。

## 7. 攻城考勤

1. 先同步同盟成员。
2. 进入「攻城任务」页面。
3. 创建任务，填写任务名称、时间、目标分组和等级规则。
4. 点击任务上的「开始考勤」。
5. 回到游戏，打开对应攻城位置的战报。
6. 采集完成后，回到软件点击统计。

说明：
- 主力/拆迁等级规则可以在任务里设置。
- 如果老任务没有等级规则，统计前软件会要求你先补规则。

## 8. 查询和导出

常用页面：

- 「队伍查询」：看成员队伍、战法、宝物和相关战报。
- 「队伍胜率」：看队伍胜率统计。
- 「同盟成员」：看成员、势力、武勋，并导出表格。
- 「攻城任务」：看考勤、统计和总览。

页面上有「导出」按钮的地方，可以导出 Excel。

## 9. 常见问题

### 软件打不开

先尝试：
1. 右键软件图标。
2. 选择「以管理员身份运行」。

如果还是打不开，可能是杀毒软件拦截了，请把软件目录加入信任。

### 抓不到数据

检查：
- Npcap 是否安装。
- 游戏是否已经打开到对应页面。
- 软件采集模式是否已经开启。
- 当前数据库是不是你想写入的库。

### 自动翻页不能用

检查：
- MuMu 是否启动。
- 是否选中了正确的模拟器实例。
- ADB 检查连接是否成功。
- 游戏窗口是否停留在同盟战报列表。

### 数据库不对

在软件的数据库选择页面重新选择或新建数据库。  
首页会显示当前实际连接的数据库。

### 换电脑后数据还在吗

安装包里带了一份默认数据库。  
软件使用过程中新产生的数据保存在安装目录下：

```text
data\default.db
```

如果要备份，把这个 `.db` 文件复制出来即可。

## 10. 最短使用流程

第一次使用可以照这个流程：

1. 安装软件。
2. 安装过程中完成 Npcap。
3. 打开 MuMu 和游戏。
4. 打开 stzbHelper。
5. 同步同盟成员。
6. 开启战报采集。
7. 游戏里打开同盟战报。
8. 回软件查看队伍查询、胜率或考勤。
